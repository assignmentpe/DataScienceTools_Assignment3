  THE MAIN TECHNICAL FINDING
  R does not have one definition of a quartile. R's own
  boxplot.stats() uses stats::fivenum() (Tukey's hinges), while the
  quantile() call almost every tutorial uses is type 7. On 1000 random vectors these two gave different quartiles on 521 of them (52.1%).
  So a perfectly correct function can still disagree with R's own
  boxplot, and both answers are right. That is why remove_outliers()
  takes a method argument, and why its default is "tukey".

PART 5  The coef argument is actually used
--------------------------------------------------------------------------

  coef = 0.5  fences [   15.31,    61.91]  ->  36 outliers
  coef = 1    fences [    3.66,    73.56]  ->  14 outliers
  coef = 1.5  fences [   -7.99,    85.21]  ->   6 outliers
  coef = 2    fences [  -19.64,    96.86]  ->   3 outliers
  coef = 2.5  fences [  -31.29,   108.51]  ->   2 outliers
  coef = 3    fences [  -42.94,   120.16]  ->   1 outliers

  Raising coef widens the fences, so fewer values are flagged.
  That is correct, and it is impossible with version 1, which always
  applies 1.5 and offers no way to change it.
